1. Project Overview

Tickle Right operates learning centres across Mumbai and Pune. Centre Lead Tracker is an internal MVP for recording enquiries, scheduling follow-ups, and tracking conversions across centres and sales owners.

2. Features

ModuleWhat it does
Lead ManagementCreate, view, edit, archive/restore leads. Phone duplicate detection. Closed leads restrict edits to notes only.
Follow-upsAdd/edit/delete per lead. Reverse chronological timeline. Auto-advance New → Contacted on Interested/Connected outcomes. Overdue badge.
DashboardStat cards, status bar chart, centre/owner tables, overdue list. Filters: date range, centre, owner, status.
CSV ExportFiltered lead list as CSV. Timestamps in UTC ISO 8601.
AdminCentre/owner management. Admin status override (e.g., Converted → Contacted).
Audit LogEvery status change recorded with old/new status, changed by, and reason. (Rule: 31716)

3. Database Design

TablePurpose
centres5 learning centres (name, city, address, phone)
owners4 team members (name, email, is_admin)
leads25 enquiry records — parent/child info, phone, status, centre, owner, timestamps
followupsActivity log per lead — channel, outcome, notes, next follow-up date
archive_logsArchive/restore audit trail
status_audit_logsStatus change audit trail — old, new, by whom, reason

Key Indexes

  • phone_normalized — duplicate detection (equality lookup)
  • status — dashboard GROUP BY + filter
  • (is_archived, status) — composite for dashboard chart
  • next_followup_at — overdue detection query
  • lead_id on followups & status_audit_logs — per-lead lookups

4. Phone Normalization

Strip all non-digits, remove leading zeros, keep last 10 digits.
+91 98765 43210 → 9876543210  |  09876543210 → 9876543210  |  987-654-3210 → 9876543210
Stored in phone_normalized. Duplicate check runs only on active (non-archived) leads.

7. Decision Log

DecisionRationale
Phone normalizationHandles all Indian formats (+91, 0-prefix, spaces, dashes). Single normalized column for fast duplicate lookups.
Soft delete with restoreLost leads may become opportunities again. Archive logs provide audit trail. Restore checks phone duplicates.
Knex.js over raw SQLMigration system + query builder prevents SQL injection. Schema is version-controlled.
Closed leads — notes onlyConverted/Lost are final decisions. Full edits would corrupt pipeline data.
Bar chart for statusShows pipeline health at a glance — most important view for the team.
Status audit logAccountability for every pipeline movement without requiring authentication.

10. Known Limitations & Future Scope
