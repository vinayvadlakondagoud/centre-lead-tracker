1. Project Overview

Tickle Right operates multiple learning centres across Mumbai and Pune. Sales and operations teams need a lightweight internal tool to record parent enquiries, schedule follow-ups, and track conversion pipeline. Centre Lead Tracker is the working MVP addressing this need.

Candidate-specific rule (code 31716, last digit 6): An audit log for status changes records every pipeline movement with old status, new status, who changed it, and why — covering manual edits, admin overrides, and auto-advances from follow-up outcomes.

3. Core Features

ModuleDetails
Lead ManagementCreate, view, edit, archive/restore. Duplicate phone detection via normalized phone. Closed leads (Converted/Lost) restricted to notes-only editing.
Follow-up ManagementAdd/edit/delete follow-ups per lead. Reverse chronological timeline. Auto-advance New → Contacted on Interested/Connected outcome. Overdue badge when next follow-up is past due.
DashboardStat cards (total, new, demos, converted, lost, overdue, archived). CSS bar chart for status distribution. Tables by centre and owner. Overdue leads table. Filterable by date range, centre, owner, status.
CSV ExportFiltered lead list download. Timestamps in UTC ISO 8601 format. IST conversion at UI display level.
Admin EndpointsCentre/owner CRUD. Admin status override (e.g., Converted → Contacted) bypassing closed-lead restriction.
Status Audit LogEvery status change logged with old/new values, changed_by, and reason. Covers create, update, admin override, and auto-advance. Visible via "Audit Log" button on Lead Detail page. (Rule: 31716)
Soft Delete with RestoreArchive hides leads from default view. Restore checks phone duplicates. Archive/restore actions tracked in archive_logs table.

6. Phone Normalization & Date Handling

Phone: Strip all non-digits, remove leading zeros, keep last 10 digits.
+91 98765 43210 → 9876543210  |  09876543210 → 9876543210  |  (987) 654-3210 → 9876543210
Stored in phone_normalized; duplicate check runs only on active (non-archived) leads.
LayerFormat
MySQLUTC via DATETIME columns
Backend APIReturns raw UTC; utility functions for IST conversion
Frontend UIformatIST() using en-IN locale, Asia/Kolkata timezone
CSV ExportUTC ISO 8601 (e.g., 2026-07-26T12:30:00.000Z)

7. Decision Log

#DecisionRationale
1Phone normalization — last 10 digits, strip non-digitsHandles all Indian phone formats (+91, 0-prefix, spaces, dashes). Single normalized column enables fast duplicate lookups.
2Soft delete with restoreLost leads may become opportunities again. Archive logs provide audit trail. Restore checks phone duplicates before allowing restoration.
3Knex.js over raw SQLMigration system + query builder reduces boilerplate, prevents SQL injection, makes schema version-controlled.
4Closed leads — notes-only editingConverted/Lost represent final decisions. Full edits would corrupt pipeline data integrity.
5Bar chart for status distributionShows pipeline health at a glance — most important dashboard view for a centre lead tracking team.
6Status audit log (Rule: 31716)Every status change recorded with old/new values, who changed it, and why. Provides accountability without requiring authentication.
