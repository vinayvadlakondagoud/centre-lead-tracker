1. Project Overview

Tickle Right operates multiple learning centres across Mumbai and Pune. The sales and operations teams need a lightweight internal tool to record enquiries, schedule follow-ups, and track conversions. Centre Lead Tracker is the working MVP built for this purpose — a full-stack web application with a React frontend, Node.js/Express backend, and MySQL database.

3. Core Features

ModuleWhat It Does
Lead ManagementCreate, view, edit, archive/restore leads. Phone duplicate detection. Closed-lead restriction (notes-only editing).
Follow-up ManagementAdd/edit/delete follow-ups. Reverse chronological timeline. Auto-advance: New → Contacted on positive outcome. Overdue badge when past due.
DashboardStat cards, bar chart (status distribution), tables by centre/owner, overdue list. Filters: date range, centre, owner, status.
CSV ExportFiltered lead list download. UTC ISO 8601 timestamps for spreadsheet compatibility.
Admin PanelCentre/owner CRUD. Admin status override (e.g., Converted → Contacted).
Status Audit LogEvery status change recorded with old/new values, who changed it, and why. Covers manual edits, admin overrides, auto-advances. (Rule: 31716)
Soft Delete + RestoreArchive leads (hidden, not deleted). Restore with phone duplicate check. Audit trail in archive_logs table.

6. Phone Normalization & Date Handling

Phone Deduplication

Rule: Strip non-digits, remove leading zeros, keep last 10 digits.
+91 98765 43210 → 9876543210
09876543210 → 9876543210
987-654-3210 → 9876543210

Stored in phone_normalized. Duplicate check runs on active leads only.

Date & Time Flow

LayerFormat
MySQLUTC (DATETIME)
Backend APIReturns raw UTC
Frontend UIIST via formatIST() — en-IN, Asia/Kolkata
CSV ExportUTC ISO 8601

7. Decision Log

#DecisionRationale
1Phone normalization — last 10 digitsHandles all Indian formats (+91, 0-prefix, spaces, dashes). Simple equality check for fast duplicate detection.
2Soft delete with restoreLost leads may become opportunities again. Archive logs provide audit trail. Restore checks phone duplicates.
3Knex.js over raw SQLMigration system + query builder reduces boilerplate, prevents SQL injection, version-controlled schema.
4Closed leads — notes-only editingConverted/Lost are final decisions. Full edits would corrupt pipeline data.
5Bar chart for status distributionShows pipeline health at a glance — most important dashboard view for the team.
6Status audit log (Rule: 31716)Tracks every status change with old/new values, who changed it, and why. Accountability without auth.
