1. Business Scenario

Tickle Right operates multiple learning centres across Mumbai and Pune. The sales and operations teams need a lightweight internal application to record enquiries, schedule follow-ups, and track conversions. Centre Lead Tracker is the working MVP built for this purpose.

3. Core Features Implemented

ModuleFeatures
Lead ManagementCreate, view, edit, archive/restore leads. Duplicate phone detection. Closed-lead editing restriction (notes-only).
Follow-up ManagementAdd/edit/delete follow-ups per lead. Reverse chronological timeline. Auto status advance (New → Contacted). Overdue badge.
DashboardStat cards, bar chart (status distribution), tables by centre/owner, overdue follow-up list. Filterable by date range, centre, owner, status.
CSV ExportFiltered lead list download as CSV with UTC ISO 8601 timestamps.
Admin EndpointsCentre/owner management. Admin status override (e.g., Converted → Contacted).
Status Audit LogEvery status change recorded: old/new status, who changed it, reason. Covers manual edits, admin overrides, and auto-advances. (Rule: 31716)
Archived LeadsSoft delete with restore. Phone duplicate check on restore. Archive/restore audit trail in archive_logs table.

6. Phone Normalization & Duplicate Prevention

Rule: Strip all non-digits, remove leading zeros, keep last 10 digits.
Example: +91 98765 43210 → 9876543210  |  09876543210 → 9876543210  |  987-654-3210 → 9876543210
Storage: Original in phone, normalized in phone_normalized. Duplicate check runs only on phone_normalized for active (non-archived) leads.

7. Date & Time Handling

LayerStorage / Format
MySQLUTC via DATETIME columns. All timestamps stored as UTC.
Backend APIReturns raw UTC values. Utility functions convert UTC → IST for display.
Frontend UIformatIST() converts to en-IN locale with Asia/Kolkata timezone.
CSV ExportUTC ISO 8601 format (e.g., 2026-07-26T12:30:00.000Z). Spreadsheet apps can localise on import.

8. Decision Log

#DecisionRationale
1Phone normalization — last 10 digits, strip non-digitsHandles all Indian phone formats (+91, 0-prefix, spaces, dashes). Single normalized column enables fast duplicate lookups via simple equality check.
2Soft delete with restoreLost leads may become opportunities again. Archive logs provide audit trail. Restore checks for phone duplicates before allowing restoration.
3Knex.js over raw SQLMigration system + query builder reduces boilerplate, prevents SQL injection, and makes schema version-controlled.
4Closed leads — notes-only editingConverted/Lost leads represent final decisions. Allowing full edits would corrupt pipeline data.
5Bar chart for status distributionShows pipeline health at a glance — most important dashboard view for a centre lead tracking team.
6Status audit log (Rule: 31716)Every status change recorded with old/new values, who changed it, and why. Provides accountability without requiring authentication.
